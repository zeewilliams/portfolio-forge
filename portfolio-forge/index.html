  1. 
          01

    We detect the platform (THM, HTB, Pluralsight, Azure, AWS, Splunk, LetsDefend, Coursera, GCP) and pick a matching template.
    
          
    
        
    2. 
        
  2. 
          02
          
    
            
    Add your name + notes
    
            
    Drop in whatever lab notes you have. Even one sentence helps the template fill in the right details.
    
          
    
        
    3. 
        
  3. 
          03

    4. 
        
  4. 
          04
          
    
            
    Drop it into GitHub
    
            
    Unzip → create a new GitHub repo → drag the files in. The included UPLOAD-GUIDE.md walks you through every click.
